# Kuiva – dry asphalt map for Helsinki

Street-level map of how much of the pavement is dry, for inline skating in Helsinki.
Built from FMI rain radar and weather stations, MET Nordic and FMI Harmonie forecasts,
Fintraffic road sensors and cameras, City of Helsinki building data, and a version of
FMI's open-source RoadSurf road weather physics with street-canyon effects.

Open: https://joukops.github.io/kuiva/
